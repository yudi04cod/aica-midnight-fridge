An entry for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun. The program writes one line of text roasting a smart fridge that refuses to open after midnight.

The roast:

> My fridge locks itself at midnight like a bouncer — mate, you're a humming box of leftovers, not a nightclub.

## How to run

```sh
python3 main.py
```

It writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Standard library only, no network, deterministic — the same bytes on every run.
